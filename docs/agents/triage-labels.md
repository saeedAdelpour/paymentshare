# Triage labels

Use these values in each issue's `Status:` line when triaging.

| Role / status | Meaning |
| --- | --- |
| needs-triage | Maintainer needs to evaluate the issue |
| needs-info | Waiting on the reporter for information |
| ready-for-agent | Fully specified and ready for agent implementation |
| ready-for-human | Requires human implementation |
| wontfix | Will not be actioned |

Canonical roles map directly to these same strings.
Wayfinding tickets use the separate lifecycle in `issue-tracker.md`.
