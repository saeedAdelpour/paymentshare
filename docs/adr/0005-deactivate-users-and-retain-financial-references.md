# Deactivate users and retain financial references

Initial administration deactivates users instead of physically deleting them. Deactivation blocks Payment Share access while retaining memberships, financial records, and actor history. The external identity-provider account remains intact, and explicit reactivation restores access subject to current permissions.

Physical deletion would undermine shared financial references and retained history. A successful provider login therefore does not reactivate a deactivated application user. The user accepted this policy on 2026-11-03.
